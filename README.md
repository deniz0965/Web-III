## ARAŞTIRMA
GİTHUB NEDİR?
GitHub: Git altyapısını kullanan projeleri internet üzerinden bulutta barındıran, başkalarıyla paylaşmayı ve ekip halinde çalışmayı kolaylaştıran web servisidir. (Yani Git bir araç, GitHub ise bu aracın buluttaki buluşma noktasıdır.) 
https://github.com/mkdemir/Git_ve_Github_Rehberi
GİT NEDİR?
Git: Bilgisayarınızdaki dosyaların ve kodların geçmişini takip etmenizi sağlayan bir sürüm kontrol sistemidir.
https://github.com/mkdemir/Git_ve_Github_Rehberi
GİT VE GİTHUB ARASINDAKİ FARK NEDİR?
Git, bilgisayarınıza kurduğunuz ve yazdığınız kodun geçmişini (sürümlerini) yerel olarak takip etmenizi sağlayan bir versiyon kontrol sistemidir. GitHub ise, Git ile oluşturduğunuz bu kod depolarını bulutta (internet üzerinde) saklamanızı, yedeklemenizi ve başkalarıyla ortaklaşa çalışmanızı sağlayan web tabanlı bir platformdur.
https://github.com/mkdemir/Git_ve_Github_Rehberi
RESPOSİTORY NEDİR?
Repository (kısaca repo), bilgi, belge, veri veya yazılım kodlarının düzenli bir şekilde saklandığı, yönetildiği ve gerektiğinde erişildiği depo veya havuz anlamına gelir.
https://tureng.com/tr/turkce-ingilizce/repository
COMMİT NEDİR?
Commit, yazılım geliştirme süreçlerinde projenin o anki durumunun kalıcı bir fotoğrafını çekmek ve kaydetmek anlamına gelir.
https://medium.com/@mustafazahidefe/git-notlar%C4%B1-3-git-commit-96439510aef0
BRANCH NEDİR?
GitHub'da (ve genel olarak Git versiyon kontrol sisteminde) branch (Türkçe adıyla dal), projenizin ana kodundan bağımsız olarak yeni özellikler geliştirmek, hataları düzeltmek veya fikirleri denemek için oluşturulan güvenli bir kopya veya çalışma alanıdır.
https://www.kritm.com/blog/github-nedir/
MERGE NEDİR?
GitHub ve Git dünyasında merge (birleştirme), farklı bir kolda (branch) yapılan kod değişikliklerini ana kola (örneğin main veya master) ya da başka bir dala entegre etme işlemidir.
https://github.com/mkdemir/Git_ve_Github_Rehberi
CLONE NEDİR?
GitHub'da clone (klonlama), uzak bir sunucuda (GitHub) bulunan bir projenin (depo/repository) tüm dosyalarını, geçmişini, dallarını ve ayarlarını kendi yerel bilgisayarınıza veya sanal ortamınıza birebir kopyalama işlemidir.
https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository
PULL NEDİR?
Git'in 4 uzak işlemden biridir. komutunu çalıştırmadan git pull, yerel deponuz uzak depodaki değişikliklerle asla güncellenmeyecektir. git pullUzak bir depoyla etkileşim kurduğunuz her gün, en azından komutunu kullanmalısınız. Bu nedenle git pullen çok kullanılan Git komutlarından biridir.
https://github.com/git-guides/git-pull
PUSH NEDİR?
GitHub ve Git terminolojisinde push, yerel bilgisayarınızda (kendi cihazınızda) yaptığınız ve commit ederek kaydettiğiniz kod değişiklerini, GitHub üzerindeki uzak depoya (remote repository) gönderme işlemidir.
https://www.datacamp.com/tr/tutorial/git-push-pull
.GİTİGNORE DOSYASININ TEMEL AMACI NEDİR?
.gitignore dosyasının temel amacı, bir Git reposunda (deposunda) hangi dosya ve klasörlerin Git tarafından izlenmemesini (takip edilmemesini) sağlamaktır.
https://medium.com/@Nuran_Tarhan/gitignore-nedir-gitte-dosyalar%C4%B1-g%C3%B6rmezden-gelmenin-g%C3%BCc%C3%BC-af577e740f02

Commit Sayısı:	~16.500+
Contributor Sayısı:	~1.650+
Klasör Yapısı:	Modüler yapıdadır; packages (alt paketler), scripts, fixtures ve compiler gibi temel klasörlere ayrılmıştır.
README Yapısı:	Kısa açıklama, dokümantasyona yönlendirme linkleri, kurulum rehberi, katkıda bulunma (contributing) kuralları ve lisans içerir.

2. Next.js
GitHub Adresi:	https://github.com/vercel/next.js
Programlama Dili:	TypeScript / JavaScript
Kullanılan Framework:	React tabanlıdır

Commit Sayısı:	~35.000+
Contributor Sayısı:	~3.200+
Klasör Yapısı:	packages/next ana kodu barındırırken, examples klasöründe kullanım örnekleri, test klasöründe test dosyaları yer alır.
README Yapısı:	"Nasıl kullanılır", proje amaçları, özellikler (Features), sponsorlar listesi, katkı sağlama yönergeleri ve lisans şeklinde yapılandırılmıştır.

3. Django
GitHub Adresi:	https://github.com/django/django
Programlama Dili:	Python
Kullanılan Framework:	Kendisidir (Python Web Framework)

Commit Sayısı:	~35.500+
Contributor Sayısı:	~2.500+
Klasör Yapısı:	Core framework kodları django klasöründe, kullanım kılavuzları docs klasöründe, testler ise tests klasöründe bulunur.
